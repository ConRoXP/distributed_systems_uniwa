-- ask1.x:
Data type and function declaration for the rpcgen utility
rpcgen -a -C ask1.x

-- ask1_server.c:
One of the files that the rpcgen utility generates based on the .x file.
Here we implement the bodies of the functions the RPC server will use for the calculations

-- socket server and client
server_sock.c and client_sock.c files (not generated by rpcgen)

-- Makefile
We need to compile three files with multiple arguments
We create the Makefile and just type make in the cmd prompt to handle this.

-- Execution
Open three terminal tabs and run:
1. RPC server
2. Socker server
3. Socket client
